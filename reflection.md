Using Figma helped me understand how my website was supposed to look before I started changing my HTML and CSS. I could use the design to check the colors, card sizes, spacing, images, and text and then recreate those details with my own code.

The most challenging part was getting the spacing and sizing to match the Figma design. I had to make several changes to my CSS, especially with the margins, padding, width, and height, because even small differences could change how the final page looked.

Frontend Mentor gives me a way to compare my HTML and CSS with how other developers completed the same project. I can also use feedback to understand what I could have done differently and learn better ways to write my code as I get more experience.
